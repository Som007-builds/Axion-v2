Decision procedure (short copy) — open the full guideline

docs/eval/DEPENDENCY_GUIDELINE.md

RELIES_ON: B's claim/argument is supported by, derived from, or conditional on a specific claim in A. Counterfactual: if A's claim were removed or invalidated, B's assertion would need to change.

MENTIONS: B cites A, but B's claim does not depend on A's specific claim. Background, credit, topic pointer, standard method/tool, or contrast that B's claim survives.

UNRELATED: the marker does not actually connect the asserted content to A (reference fragment, misattribution, or no assertion about A).

  1. Resolve the target A. Multiple sources in one marker: label each source separately.
  2. Read the sentence, paragraph, and section; do not label from the reference title alone.
  3. State B's assertion in this context.
  4. Run the counterfactual. Yes → RELIES_ON; no but still refers → MENTIONS; no and not about A → UNRELATED.
  5. If the text is genuinely insufficient, use insufficient_context: leave the label blank, write a note, and do not guess.
