## Measured P1 quality (the only gold measurement that exists)

- Audited precision **96.5%** — **193/200** claims `CORRECT`; 7 `NOT_A_CLAIM`; 0 `DISTORTED`,
  0 `UNSUPPORTED_SPAN`, 0 `DUPLICATE`.
- Wilson 95% CI **93.0–98.3%**; paper-level cluster bootstrap (45 papers, 2,000 resamples, seed
  20261114) **94.0–98.6%**.
- Independent second labeler on the seeded 40-claim overlap: **40/40 `CORRECT`**, raw agreement
  **100%**, Cohen's κ **not estimable** (degenerate, one label class).
- Caveat: the 40-claim overlap contained **no `NOT_A_CLAIM` rows**, so agreement on the error
  class is **unmeasured**, not 100%.

## Known limits that P2 must repeat in every report

1. **Single primary labeler.** Agreement is one independent 20% overlap; it does not validate the
   error class.
2. **Precision only.** The gold set samples baseline output; **absolute recall is unknown**. No
   claim about missed claims can be made from this gold set.
3. **Claims within a paper are not independent**; 45 clusters is still a small number of papers.
4. Gold measures the P1 baseline's output only. A P2 configuration can only be scored on gold where
   its output aligns with a gold-labelled baseline claim; anything else is **unverifiable**, not
   correct.
5. The 7 `NOT_A_CLAIM` rows are background/procedural sentences. A prompt that suppresses them is
   a candidate P2 lever, but the baseline prompt stays frozen.
6. Corpus link coverage is conditional on the included citer set: 285/792 sources have an incoming
   citer edge; 507 do not (ADR-0015 Proposed; P3 owns expansion).

## Gotchas

- No GNU `make` on this host. Use `.venv/Scripts/python.exe` and `scripts/*.py`; `make report`
  maps to `python scripts/build_p1_report.py`.
- Pre-commit hook environments must be installed with system Python **3.12**
  (`py -3.12 -m pre_commit install --install-hooks`); the 3.11 venv base at `D:\` breaks
  virtualenv. The project itself runs on Python 3.11.9 in `.venv`.
- `AXION_DRY_RUN=true` is set in `.env`. A live run requires the command-local environment
  override `AXION_DRY_RUN=false`; do not edit `.env`.
- The free-tier daily counter is the ledger, per model, per Pacific day, counted in **attempts**
  including failures. Retries consume quota. A daily-quota stop is clean and resumable.
- `pricing.yaml` has no entry for `gemini-3.1-flash-lite` or Gemma; a call to an unpriced model
  records no cost (warning outside dry-run). Do not invent a price.
- Chroma emits telemetry warnings; harmless. Neo4j runs on host ports 7475/7888 (V1 uses
  7474/7887).
- The full-text JATS cache, `data/chroma-full`, and the Neo4j volume are untracked and required to
  reproduce store loads. Do not delete them.
- `_private/` is untracked; never quote it in tracked files.
