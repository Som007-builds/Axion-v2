# P2 student — claim-sentence selector

> Generated by `python scripts/train_student.py`. Encoder: `sentence-transformers/all-MiniLM-L6-v2` (frozen) + logistic head. Student version `student-v1-minilm-lr`; artifact SHA-256 `e6ac79d6c8148fe9…`.
> **Gold measures precision only.** Retention is agreement with the baseline's own
> audited output, **not recall**; absolute recall is unmeasured. Claims that align
> with no gold row are **unverifiable** and are never counted as correct.

## Training data (silver, gold-free)

- **98** non-gold papers (88 with at least one teacher claim) with teacher claims from the P1 baseline and P2-03a; **16,452** sentences, **650** positive sentences.
- Split by paper; 15 papers held out for a teacher-agreement diagnostic, then the final model is refit on all non-gold papers. All **45 gold papers are excluded by paper ID and the build fails closed if one appears**.
- Negatives are all other sentences in the same papers. Teacher omissions are label noise and are documented as the main limit.

## Operating rule (fixed before test scoring)

- Emit the top **k = 8** sentences per paper, matching the baseline's mean claim budget on gold papers (8.47 claims/paper). The dev sweep is reported for the cost/quality trade-off, but the test split is scored once at this fixed budget.

## Limits (repeat in every P2 report)

- **Precision is conditional on alignment.** Unverifiable output is counted, never scored; most student output is unverifiable because gold sampled only 200 baseline claims.
- **Retention is not recall.** It measures agreement with the audited baseline output. A claim the baseline never emitted cannot be counted as lost.
- 45 gold papers is a small cluster count; claims within a paper are not independent.
- Encoder is frozen (pretrained MiniLM); only the linear head is trained. End-to-end fine-tuning was tested on dev and did not improve the operating point enough to justify its 48-minute CPU cost (29.1% vs 27.2% retention at k=8, two rows).
- CPU inference is measured here; production cost depends on deployment and is a projection, not this measurement.
- No model was adopted; the P1 baseline remains frozen.
